# Workflow and output checklist

1. Read source files and bind the active host document.
2. Record confirmed facts, assumptions, conflicts, and pending conditions.
3. Analyze site, function, adjacency, entrances, circulation, structure, levels, and applicable code sources.
4. Establish a spatial scheme before detailed drafting.
5. Draft host-native architectural objects and keep layers editable.
6. For Tianzheng object conversion, reconstruct the actual outline and verify continuity before replacing or flattening an object.
7. Inspect the actual CAD viewport after each major stage.
8. Run geometry, architectural, and drafting checks.
9. Save a new output copy, preserve the source, and report unverified items.

Minimum output sections are source-condition recognition, design logic, drawing deliverables, circulation and structure notes, code precheck, CAD error report, and pending verification items.
